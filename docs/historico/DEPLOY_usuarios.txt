RetoPA — Panel Usuarios más útil (último acceso + enviar correo) + fix KPIs
════════════════════════════════════════════════════════════════════════════

QUÉ SE AGREGA / ARREGLA
──────────────────────────────────────────────────
1) Columna "Último acceso" (desde last_seen_at, que ya se registraba):
   "En línea" / "Hoy HH:MM" / "Ayer" / "hace N días" / "hace N meses" / "Nunca",
   con color por recencia → ves de un vistazo quién está activo y quién dormido.
2) Acción "Enviar correo" (avión verde) por usuario: abre un modal, elegís una
   plantilla y se manda al email del usuario. Si el usuario tiene ficha propia,
   la usa como datos para los placeholders ({businessName}, etc.). Reusa
   /notify/send-template y queda en Logs de correos. Ideal para invitar a los
   dormidos a usar el sistema, mandar tips, bienvenidas, etc.
3) FIX de las tarjetas KPI (bonus):
   · "Total" mostraba 1 → era un bug: la consulta de conteo arrastraba el
     GROUP BY. Ahora el total es correcto.
   · "Activos / Clientes / Admins / GodMode" contaban SOLO la página actual
     (máx 25). Ahora el backend devuelve conteos GLOBALES y las 5 tarjetas son
     correctas sin importar filtro ni página.
